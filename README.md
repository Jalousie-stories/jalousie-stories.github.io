# jalousie-stories.github.io

This is the personal site of ＠jalousie, a writer of interactive romance stories on ISEKAI ZERO, served by GitHub Pages at https://jalousie-stories.github.io from the root of the `main` branch. It is a single page of plain HTML and CSS (`index.html`, `styles.css`, `404.html`) with no JavaScript, no build step, no tracking and no cookies: edit the files and push to `main`, and Pages publishes them as they are.
